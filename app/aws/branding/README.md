# Branding

This folder is the product's default branding: none. A stack deployed from
source uses it, and shows its `InstitutionName` in the top bar, in the
`AccentColor` it is given.

An instance's own branding lives in its instance repo, in a folder of the same
name beside `understory.yml`. Its slots are listed in
`ui/src/lib/branding.js`. This README is never published.
